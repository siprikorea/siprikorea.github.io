Flow

Build data pipelines visually.

Flow is a node-based dataflow editor — drag modules onto a canvas, wire them together, and run the pipeline. Transform, encrypt, hash, merge, and split data without writing code.

⬇ Download for macOS All releases

Free, and built with Kotlin Multiplatform. Windows & Linux coming soon.

Visual canvas

Drop modules on an infinite canvas and connect their ports. Watch data travel the wires as your pipeline runs.

Extensible

Write your own module as a small JAR and install it — no rebuild of the app required.

Byte-accurate

Ports carry raw bytes, with hex and string editors built in, so binary data stays intact end to end.

Built in

Six modules ship with Flow out of the box.

Crypto — AES / DES / 3DES / Blowfish, selectable mode & padding Hash — MD5 / SHA-1 / SHA-256 / SHA-512 Base64 — encode / decode Merge Split Sleep
