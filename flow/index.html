01 — Canvas캔버스

The flow is exactly what's on screen

흐름은 화면에 그려진 그대로다

Drag input, processing and output modules onto the canvas and connect them with wires. On run, each node changes color, so you can see how far it got and where it stopped — right on the canvas.

입력 · 처리 · 출력 모듈을 끌어 놓고 선으로 잇습니다. 실행하면 각 노드의 색이 바뀌므로 어디까지 진행됐고 어디서 멈췄는지 캔버스에서 바로 보입니다.

Unconnected ports are flagged before the run, and the minimap at the bottom right shows where you are once the flow grows past the screen.

연결되지 않은 포트는 실행 전에 표시되고, 오른쪽 아래 미니맵이 흐름이 화면 밖으로 커졌을 때 현재 위치를 알려 줍니다.

02 — Modules모듈

Four kinds, that's all

네 종류가 전부다

Only four things can go on a Flow, and the color tells you which is which. Together they are called modules.

Flow에 놓을 수 있는 것은 네 가지뿐이고, 색만 봐도 어느 쪽인지 알 수 있습니다. 이 넷을 아울러 모듈(Module)이라고 부릅니다.

INPUT

Input

입력

Holds the values that enter the flow. Type them as a string or hex, or feed in a file.

흐름에 들어갈 값을 담당합니다. 문자열과 16진수로 입력하거나, 파일을 그대로 넣을 수 있습니다.

PROCESSOR

Processor

프로세서

Takes a value, processes it and emits a result. Hashing, encryption, signing and encoding happen here.

값을 받아 처리하고 결과를 내보냅니다. 해시 · 암호화 · 서명 · 인코딩 같은 실제 작업이 여기서 일어납니다.

OUTPUT

Output

출력

Receives the processed result so you can read it — as a string, as hex, or in an output module you wrote yourself.

처리된 결과를 받아 확인합니다. 문자열 · 16진수로 보거나, 출력 모듈을 직접 만들어 원하는 형태로 볼 수 있습니다.

FLOW

Part

부품

Drop a saved flow into another flow as a single module. A combination you use often simply becomes a part.

저장해 둔 흐름을 다른 흐름 안에 모듈 하나로 넣습니다. 자주 쓰는 조합이 그대로 부품이 됩니다.

03 — Market마켓

Install only what you need

필요한 것만 골라 설치

From the market in settings, install and remove modules published to the module repository, and update them when a new version lands. Everything installed collects in the module list, ready to drag straight onto the canvas.

설정 화면의 마켓에서 모듈 저장소에 올라온 모듈을 설치하고 삭제하며, 새 버전이 나오면 업데이트합니다. 설치한 모듈은 모듈 리스트에 모이고, 거기서 캔버스로 바로 끌어다 쓰면 됩니다.

04 — AI

Build and edit a Flow with AI

AI로 Flow를 만들고 고친다

Describe the flow you want and AI assembles the complicated parts for you. Feed in the data, run it, read the result — and edit the generated flow by hand on the canvas whenever you like.

원하는 흐름을 말로 설명하면 AI가 복잡한 Flow를 대신 구성합니다. 데이터만 넣고 실행해 결과를 확인하세요. 만들어진 Flow는 언제든 캔버스에서 직접 손볼 수 있습니다.

05 — Views결과 보기

Read the result the easy way

결과를 쉽게 확인

Some things a string or a hex dump will never tell you. Extend the output module and read the result in the view that suits it.

문자열이나 16진수만으로는 알 수 없는 것이 있습니다. 출력 모듈을 확장해 필요한 화면에서 결과를 보세요.

ASN.1 — structure beside bytes

ASN.1 — 구조와 바이트를 나란히

Signature data in hex tells you almost nothing about what was produced. Pick a node in the DER tree on the left and its hex appears on the right, with Tag and Length below.

전자서명 데이터는 16진수만 봐서는 무엇이 만들어졌는지 알기 어렵습니다. 왼쪽 DER 트리에서 노드를 고르면 오른쪽에 해당 구간의 16진수가, 아래에 Tag와 Length가 표시됩니다.

IMAGE — image data as an image

IMAGE — 이미지 데이터는 이미지로

See the image a processor produced exactly as it is, with its metadata alongside.

프로세서가 만든 이미지를 그대로 띄워 보고, 이미지 메타데이터까지 함께 확인합니다.

Your own views, and anything else you need

원하는 뷰까지, 원하는 무엇이든

Write modules, save flows as parts, extend the result views. Flow is the bench you assemble them on.

모듈을 만들고, 흐름을 부품으로 저장하고, 결과 화면까지 확장하세요. Flow는 그 조립을 위한 작업대입니다.
